# Caso
El Hotel VistaMar, un establecimiento de tamaño mediano que goza de popularidad entre turistas y viajeros de negocios, enfrenta desafíos en su operatividad y experiencia del cliente debido al método actual de manejo de reservaciones que se realiza manualmente mediante llamadas telefónicas y correos electrónicos. Este sistema ha resultado en problemas como sobre-reservas y errores en la gestión de disponibilidad de habitaciones. Para mejorar la eficiencia operativa y la satisfacción del cliente, el hotel busca desarrollar e implementar un sistema de reservas en línea que permita a los clientes realizar y gestionar reservas de manera más conveniente y accesible. 

## Instrucciones:
[x] Analiza y enumera en un documento, de forma organizada, los requerimientos para este sistema de reservas, donde identifiques todas y cada una de las entidades (Clases) que se deben implementar. 

[x] Identifica los diferentes actores y entidades que interactuarán con el sistema, incluyendo clientes, personal del hotel, habitaciones, la gestión de reservas, entre otros.

[x] Crea un diagrama de clases UML que refleje las entidades involucradas en el sistema de reservas, sus atributos, métodos y las relaciones entre ellas. Asegúrate de incluir clases para gestionar las reservas, habitaciones, clientes y el personal del hotel.

[x] Define las relaciones adecuadas entre las clases, como asociaciones, composiciones y herencias. Por ejemplo, una clase Reserva podría estar compuesta por una o más Habitaciones.
